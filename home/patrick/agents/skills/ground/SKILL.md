# Ground

<!-- @include shared/rerun.md -->

Lens names at the start of the argument select lenses (`/ground assumptions
sources`); the rest of the argument is the focus.

Ground and think more on the open recommendations until each is strong; where
none is, list the decisive trade-offs. Re-verify the premises of every
recommendation you reversed.

## Lenses

Selected lenses become the deep focus of the pass.

- **assumptions:** re-verify every premise in current source, decided items
  and prior rulings included.
- **board:** find open items the result makes moot, duplicates, answers or
  contradicts; act on each.
- **sources:** read the owning docs, READMEs, sibling modules and transcripts
  not yet read before concluding.
- **probe:** settle facts by running something (a probe, a test, a count over
  real data) wherever one run settles it.
