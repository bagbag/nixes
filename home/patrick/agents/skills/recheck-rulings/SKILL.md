# Recheck rulings

On every mention of this skill, re-read this file and apply it anew to the
focus named with it, otherwise to the current discussion.

Are you sure all your own rulings are the only realistic clean option? Name
each ruling's strongest alternative and its footguns; re-check every choice you
left to another role; downgrade anything unsure to a question.
