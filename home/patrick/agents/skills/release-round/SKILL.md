# Release round

On every mention of this skill, re-read this file and apply it anew to the
focus named with it, otherwise to the current round.

If you're sure all your own rulings are the only realistic clean option,
everything else is clean too, and the decide protocol's release checks hold,
release is approved for this round's items; otherwise question me.

Before releasing, give the outputs of the Release Re-check, Board check and
Own rulings steps in `$HOME/.agents/skills/role/protocols/decide.md`, then
continue that protocol from Owner writes.
