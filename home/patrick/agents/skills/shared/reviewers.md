## Reviewers

- Scale depth to stakes and impact uncertainty; choose reviewer count separately.
- Independence is relative to authorship, including your own results; a role name
  or passing self-check is not independent.
- Start independent judgment with a fresh reviewer and a neutral brief: frame
  and sources, a proposal as object of review without endorsement; omit your
  recommendation, desired answer and earlier verdicts.
- Use the same reviewer, `deep-review` included, for clarifications, additions,
  amendments and repairs. Reuse assessments of the same target, sources and
  revision. A change to a premise the verdict rested on, or to blast radius,
  gets a fresh reviewer (global Warm reuse). Add a reviewer only for a named
  unanswered question, a user request or an Acceptance escalation
  (`$HOME/.agents/skills/shared/acceptance.md` Review policy). An explicit
  request for a fresh opinion gets a new reviewer.
- Reconcile material disagreement once: give each reviewer the other's strongest
  argument neutrally. Record new evidence, corrected premises or reweighting
  behind changed positions. Return remaining judgment differences to the decider.
