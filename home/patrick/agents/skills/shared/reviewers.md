## Reviewers

- Scale depth to stakes and impact uncertainty; choose reviewer count separately.
- Independence is relative to authorship, including lead results; a role name
  or passing self-check is not independent.
- Start independent judgment with a fresh reviewer and a neutral brief: frame
  and sources, a proposal as object of review without endorsement; omit the
  lead's recommendation, desired answer and earlier verdicts.
- Use the same reviewer for clarifications, amendments and repairs. Reuse
  assessments of the same target, sources and revision. Reopen on changed
  premises or blast radius; add a reviewer only for a named unanswered question
  or a user request. An explicit request for a fresh opinion gets a new
  reviewer; reused assessments do not satisfy it.
- Reconcile material disagreement once: give each reviewer the other's strongest
  argument neutrally. Record new evidence, corrected premises or reweighting
  behind changed positions. Return remaining judgment differences to the decider.
